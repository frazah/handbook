# Demo SQL: clienti e ordini

Con Python già installato, esegui senza dipendenze esterne:

```bash
python3 esempi/sql/run_sql.py
```

Puoi aprire `schema.sql` e `queries.sql` in VS Code e avviarli su SQLite. **Attenzione:** `schema.sql` elimina le tabelle di esempio prima di ricrearle; usalo solo su un DB di prova.
