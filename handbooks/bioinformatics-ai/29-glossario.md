# Glossario essenziale A–Z

| Termine | Definizione breve |
| --- | --- |
| Allele | Variante di un gene |
| Anticorpo | Proteina immunitaria che riconosce un bersaglio |
| Antigene | Struttura riconosciuta dal sistema immunitario |
| Assemblaggio | Ricostruzione di sequenze più lunghe da dati frammentati |
| Batch effect | Variazione tecnica non attribuibile al fenomeno studiato |
| Bioinformatics | Informatica e statistica applicate a dati biologici |
| Biosecurity | Prevenire usi impropri e accessi non autorizzati a risorse biologiche |
| Biosafety | Prevenire eventi biologici accidentali indesiderati |
| Biomarker | Caratteristica misurabile associata a un processo |
| Cellula | Unità fondamentale della vita |
| Confondente | Variabile che distorce un'associazione osservata |
| Coverage | Quanto una regione è rappresentata nelle letture |
| DNA | Molecola che conserva informazioni genetiche |
| Epigenetica | Regolazione dell'attività genica non spiegata da sole variazioni di sequenza |
| Fenotipo | Tratto osservabile dovuto a fattori genetici e ambientali |
| Filogenesi | Ricostruzione delle relazioni evolutive |
| Gene | Regione di DNA con prodotto funzionale |
| Genoma | Materiale genetico complessivo |
| Genotipo | Caratteristiche genetiche di un individuo |
| Incidenza | Nuovi eventi in una popolazione/periodo definiti |
| Metabolita | Piccola molecola coinvolta nel metabolismo |
| Omics | Misurazioni su larga scala di classi molecolari |
| One Health | Integrazione di salute umana, animale, vegetale e ambientale |
| Patogeno | Agente capace di causare malattia in certe condizioni |
| Prevalenza | Persone con una condizione in un dato momento/periodo |
| Proteina | Polimero di aminoacidi con ruoli biologici diversificati |
| Read | Sequenza letta da uno strumento |
| RNA | Famiglia di acidi nucleici con ruoli diversificati |
| Sorveglianza | Raccolta e analisi sistematica per la sanità pubblica |
| Trascrizione | Produzione di RNA da stampo di DNA |
| Traduzione | Produzione di proteina da mRNA |
| Variante | Differenza di sequenza rispetto a un riferimento |
| Zoonosi | Infezione naturalmente trasmissibile fra vertebrati ed esseri umani |

**Nota:** sono definizioni da consultazione rapida; la terminologia clinica o di laboratorio può richiedere definizioni più rigorose e circostanziate.
