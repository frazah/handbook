# React — Esercizi

1. Crea una `TaskList` con componenti `TaskCard`, `AddTask`, `Filters`.
2. Aggiungi stato con `useState`, pulsante per completare e filtri "tutte/attive/completate".
3. Il numero completate deve essere *derivato* da `tasks`, non uno state duplicato.
4. Aggiungi `fetch('/api/tasks')` con loading/error e cleanup `AbortController`.
5. Rendi form e lista utilizzabili da tastiera e prova almeno un test React Testing Library.

**Autovalutazione:** nessuna mutazione diretta di state, nessun indice come key su lista mutabile.
